# Лабораторная работа №6. Redux Toolkit, авторизация и API

## Страницы приложения

### Лента

Основная доступная страница с вертикальным просмотром карточек шин.

На странице отображаются:

- видео шины или видео по умолчанию;
- название шины;
- раскрываемое описание с кнопками «Больше» и «Меньше»;
- оптимальное давление;
- радиус колеса;
- количество лайков.

Кнопки:

- кнопка с сердцем — поставить или убрать лайк;
- кнопка со стрелкой — перейти к следующей шине.

### Плитка

Страница каталога шин в виде плитки.

На карточке отображаются:

- изображение шины или изображение по умолчанию;
- название;
- количество лайков;
- радиус колеса.

Нажатие на карточку открывает выбранную шину на странице «Лента».

На странице есть фильтр по радиусу:

- ползунок минимального радиуса;
- ползунок максимального радиуса;
- кнопка «Найти» для применения фильтра;
- подпись с количеством найденных шин.

### Добавить

Страница создания новой услуги — типа шины. Доступна только авторизованному пользователю; при попытке открыть её гостем приложение переводит пользователя на страницу «Вход».

На странице находятся поля:

- название шины;
- описание;
- радиус колеса от R13 до R22;
- оптимальное давление;
- файл изображения в формате JPEG, PNG, WebP или GIF;
- файл видео в формате MP4, MOV или WebM.

Кнопка «Добавить шину» сначала создаёт черновик услуги с файлами, затем публикует его с описанием, давлением и радиусом. Во время запроса форма блокируется и отображается индикатор загрузки.

### Вход

Страница авторизации пользователя.

На странице находятся:

- поле для логина;
- поле для пароля;
- кнопка «Войти»;
- сообщение об ошибке при неверных данных или недоступности сервиса.

После успешного входа backend устанавливает HttpOnly-cookie `sessionId`, а Redux хранит состояние интерфейса: логин пользователя и признак авторизации. В нижней навигации пункт «Вход» меняется на «Выход». При нажатии «Выход» выполняется деавторизация, состояние Redux и фильтр пользователя сбрасываются.

## Нижняя навигация

В нижней панели находятся четыре пункта:

- Лента;
- Добавить;
- Плитка;
- Вход.

Для гостя доступны только «Лента» и «Плитка».
